# 导演台 V2 需求（用户 2026-09-18）

仓库：heropopcorn/nl，主目录 `video_game/`（Godot 4 Web，已部署 https://nl-ivory.vercel.app）。
基线：main 上已有 Director Desk P0（多场景、矩形水域、单角色折线、雨、中文 HUD）。

## 总原则
- 明确区分 **编辑模式** 与 **播放模式**。
- 全中文 UI，操作逻辑清晰，能让非程序用户完成搭场景。
- 可玩性优先：改完能在 Web 导出里立刻试。
- 场景数据仍落在 `user://director_desk/`（或兼容扩展），要有迁移。
- 保留现有可用能力，不要回退。

## 1. 章节 → 场景
- 可新建 **章节（Chapter）**。
- 章节下可新建多个 **场景（Scene）**。
- 列表层级：章节展开 → 场景列表；支持重命名、删除（二次确认）、排序（可先简单上下移）。
- 播放模式可按章节顺序播放场景（至少：选中章节后顺序播；或明确「当前场景播放」+「章节连播」二选一写清）。

## 2. 场景内容：背景 + 元素 + 显示层级
- 场景可设置 **背景图**（上传 PNG）。
- 可放入元素：房屋、树木等（从现有 `art/sliced/` 资产库选，或上传透明 PNG）。
- 每个元素有 **显示层级 layer（整数）**：数值越高越靠上（越前）。
- **同 layer** 内用现有 **Y 排序**（脚底锚点）决定前后。
- 不同 layer：先比 layer，再同层 Y 排。
- 元素可拖拽摆放；锚点 bottom-center。

## 3. 底图区域圈选设层级
- 可在底图上圈选一块区域，给该区域设 **显示层级**（用于「地面某块」与角色/道具遮挡，例如矮墙、平台感）。
- 实现假设（可自证后调整）：区域遮罩层参与排序，或拆成独立排序精灵；文档写清规则。

## 4. 流水
- 当前雾气感不够：做成 **更真的流水**（可见流动、方向、至少比现有强）。
- 水域编辑：
  - 支持 **调整大小**（选中后拖拽控制点改矩形，或等价精确控制）。
  - 另支持 **套索/多边形圈选**（类似 PS 套索：点折线闭合区域），不只是一次框两个对角点。
- 每个水域区域仍可设流向；多区域可并存，尽量不重叠或重叠规则写清。

## 5. 多角色路线
- 可放多个角色实例。
- **点击角色** 才显示/编辑该角色的路线。
- 路线可 **显示 / 隐藏**（编辑态默认显示当前角色线；播放态可隐藏）。
- 每条路线可设 **行进速度**。
- 播放模式：各角色按自己的路线与速度走。

## 6. UI
- 全面中文。
- 编辑 / 播放模式切换明显。
- 左：章节/场景；中：画布；右：当前选中对象属性（层级、速度、水域流向等）。
- 去掉含糊英文按钮；危险操作要确认。

## 完成标准
- Godot 工程可运行；`--selftest` 覆盖：章节场景 CRUD、layer 排序、多角色路线、水域多边形或可调矩形至少一种精确编辑。
- Web 导出配置保持可部署到现有 Vercel 根 `video_game/`。
- 更新 `video_game/docs/director-desk/` 使用说明（中文）。
- 开 PR，标题说明 Director Desk V2。
