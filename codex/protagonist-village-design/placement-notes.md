# 人工切分与摆放说明

## 1. 地面底图进导演台

1. 启动 `video_game`，打开导演台并新建场景。
2. 选择“上传背景”，导入 `ground-protagonist-village-v1.png`；或在已建场景的“场景”页使用“更换背景”。
3. 关闭“显示内置道具”，避免原镇子建筑叠在新地皮上。
4. 用“框选水域”沿右侧主溪分成 2–4 个相邻矩形，并给灌溉沟单独框一条窄水域。矩形可共边但不能面积重叠。
5. 水流主方向设为由画面上方向下；灌溉沟从主溪向田地方向。检查角色路线不要穿过水体碰撞。

当前代码会把上传背景最长边缩至 2048，本图 1536×1024 不会触发缩放。导演台上传入口可直接处理 PNG；场景数据保存到 `user://director_desk/`。

## 2. 建筑 sheet 切分

`buildings-sheet-v1-opaque-cutout-source.png` 当前不是透明图。生成器两次透明/纯黑请求都仍产生了渐变底，因此导入 Godot 前必须人工抠底：

1. 在 Krita、Photoshop 或同类工具按 2×3 网格分别框选六栋建筑。
2. 对每栋使用前景选择/主体选择，不建议直接按单一颜色删除，因为背景是渐变。
3. 保留贴近建筑的草脚和柔和接触阴影；删除远离主体的所有底色。
4. 去边色 1–2 px，检查瓦檐、木柱、布片和草叶之间没有棕绿光晕。
5. 每栋紧裁，四周留 8–16 px 透明边；统一导出 RGBA PNG。
6. 以门槛中央作为逻辑落地点；Sprite2D 使用 bottom-center 锚点。

建议文件名：

- `village_hero_home.png`
- `village_schoolhouse.png`
- `village_neighbor_patched.png`
- `village_neighbor_leanto.png`
- `village_storage_shed.png`
- `village_field_shelter.png`

## 3. Godot 落地

当前工程内置建筑的实现位于 `video_game/scripts/village.gd`：从 `res://art/sliced/` 读取独立 PNG，再由 `PROP_LAYOUT` 的 UV、缩放和碰撞半径摆放。导演台现有界面能上传/替换背景并显示或隐藏内置道具，但没有看到任意建筑 PNG 的运行时导入和拖拽持久化入口。因此本批建筑有两种接入方式：

- 近期人工方案：把抠好的 PNG 放进 `video_game/art/sliced/`，在 `PROP_LAYOUT` 增加条目后运行场景；用下表 UV 起步微调。
- 后续导演台方案：给场景模型增加 `props[]`（asset_id、uv、scale、z、collision），再做资产栏拖放。不要把六栋房重新合成到背景图里。

推荐初始摆位：

| 地点 | 资产 | UV | 初始相对缩放 | 碰撞建议 |
|---|---|---:|---:|---|
| P01 主角家 | B01 | `(0.27, 0.64)` | 0.85 | 门前留空；碰撞只包墙体下半部 |
| P02 学舍 | B02 | `(0.51, 0.18)` | 0.95 | 比住宅略宽，不抬高 |
| P03 邻居甲 | B03 | `(0.23, 0.39)` | 0.78 | 避开西侧土路 |
| P04 邻居乙 | B04 | `(0.67, 0.41)` | 0.78 | 与溪岸至少留一人宽 |
| P05 邻居丙 | B03 镜像或后续变体 | `(0.28, 0.27)` | 0.72 | 避开西北田围栏 |
| P06 农具区 | B05 或 B06 | `(0.59, 0.63)` | 0.75 | 棚口朝主路/田地 |

若把 `village.gd` 的现有 bottom-center 规则沿用到新建筑，图像锚点应保持 `offset = (-width/2, -height)`。碰撞不要覆盖屋檐投影，也不要挡住门前土路。

## 4. 水流框选建议

- 主溪可分为上段 `(0.72,0.00)–(0.90,0.32)`、中段 `(0.77,0.27)–(0.94,0.60)`、下段 `(0.71,0.55)–(0.90,1.00)`；实际框选应贴着蓝水面再缩窄。
- 灌溉沟约在 `(0.69,0.52)–(0.84,0.61)`，独立设较慢流速。
- 木桥处不要另画水；水域保持连续，桥体碰撞负责通行。
- 这些是快速定位范围，不是最终碰撞盒；以画面蓝色像素和试玩路线为准。

## 5. 摆放验收

- 所有屋门都能接到土路，且门前至少容纳两名角色错身。
- 从村口到主角家、学舍、木桥各有清晰路线。
- 任何视角下都看不到石板十字路或圆形广场。
- 建筑最高只读成单层；烟囱不算楼层。
- 关掉建筑层后，底图仍是一张完整可走的地皮；关掉地皮后，每栋建筑仍是独立 RGBA 资产。
