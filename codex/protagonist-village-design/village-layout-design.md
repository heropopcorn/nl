# 主角村布局与美术设计

## 1. 场景定位

这是大陆东南边陲的农业小村，也是主角童年教学成长线的起点。规模应小、资源有限、生活稳定：不是灾后贫民窟，也不是富裕旅游村。所谓“穷”主要体现在材料反复修补、建筑体量小、公共设施少、道路未经铺装，而不是破败肮脏。

镜头分两套：地皮使用 strict top-down orthographic；可摆建筑使用固定 top-down isometric / orthographic oblique。两者继承批准参考的暖色手绘、轻东方、非像素 2D 游戏美术。

主路从画面下方村口进入，向上弯行并分成不规则 Y 形：一支通向西北田间，一支通向学舍和邻居住宅。右侧浅溪承担自然边界与灌溉，只有一座窄木桥；村内没有中心广场。

## 3. 功能区

### 家与邻里

主角家是普通农户住宅：单层、两开间感、旧瓦、泥灰墙和外露木梁。邻居不做整齐排屋，而是沿路错落布置；每户差异来自补瓦、柴棚、陶缸或门窗位置，不靠层数和华丽装饰区分。

### 学舍

学舍承担学前听字课和基础学堂的早期场景。它仍是单层，只比住宅略宽；可用一块无字木告示板和小铃识别。不要钟楼、学院门楼、大院墙或带魔法光效的纪念物。

### 田间与水系

两块田控制在“家庭或几户合用”尺度。小溪保持窄、浅、可亲近；导演台中的动态水流应覆盖蓝色水面，不覆盖石岸和草岸。灌溉沟只作为一条细支流，不扩成运河。

### 村口

村口是土路收窄处，只需木桩、矮篱或旧路牌之一。不要城门、石阶、牌坊和商业摊位。

## 4. 建筑套组

建筑 sheet 按从左到右、从上到下读取：

| 资产 ID | 建筑 | 外观重点 |
|---|---|---|
| B01 | 主角家 | 普通单层泥墙木屋，结构完整但朴素 |
| B02 | 学舍 | 单层略宽，木铃/告示板是唯一公共建筑标识 |
| B03 | 邻居甲 | 屋顶有明显修补，体量与主角家接近 |
| B04 | 邻居乙 | 侧边简易柴棚或斜靠棚 |
| B05 | 农仓 | 木门面积较大，无居住装饰 |
| B06 | 田间棚 | 开敞单层，用于短暂休息和放农具 |

统一要求：门是唯一地面入口层；不能有二层窗、老虎窗、塔楼或“阁楼正立面像二层”的造型。烟囱可以有，但不应让建筑显得富裕。

## 5. 与现批准镇子资产的差异

| 维度 | 现批准镇子级状态 | 主角村状态 |
|---|---|---|
| 路网 | 石板十字主路、视觉轴线明确 | 窄而弯的夯土路，不规则 Y 形支路 |
| 中心 | 圆形石砌广场/纪念性节点 | 无广场，仅有自然形成的路口宽处 |
| 住宅 | 两层体量多、蓝瓦整齐、装饰丰富 | 全部单层，旧瓦/木瓦、补丁和小窗 |
| 公共建筑 | 可出现商店、塔楼、风车等地标 | 只有略大的简陋学舍，无塔楼 |
| 材料 | 石基、完整抹灰、精致木作 | 泥灰墙、粗木梁、旧瓦、局部修补 |
| 空间密度 | 景观点密、设施丰富 | 户数少、空地多、生产空间占比高 |
| 水系 | 多桥、装饰性池塘与精致岸线 | 一条浅溪、一座窄木桥、细灌溉沟 |
| 夜间设施 | 路灯/灯柱可成体系 | 户门挂灯为主，不设公共灯列 |
| 经济观感 | 镇子/富裕农庄 | 普通边陲村，节俭但有人维护 |

## 6. 明确禁止

- 石板主干道、十字轴线、圆形石广场。
- 两层房、塔楼、市场铺面、豪华蓝釉屋顶。
- 强中式宫殿飞檐、大红灯笼、牌坊式村口。
- 以破墙、垃圾和黑暗光照表现贫穷。
- 把建筑直接烘焙进地面底图；后续可摆建筑必须保持独立。
