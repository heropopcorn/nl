## 已完成

### 1. 制作路线与动作分工已明确

- 目标形式已明确：不是制作传统完整动画，也不是让视频模型一次生成整片，而是把游戏技术当作视频生成/演出系统（Turn 1–2）。
- 人物动作采用混合路线：
  - `Idle / Talk / Blink / Nod / Wave / Point` 等小幅二维、重复动作适合骨骼或换图；
  - 转身、奔跑、翻滚、打斗、挥刀、复杂交互等动作适合 AI 视频生成后抽帧为 Sprite 序列（Turn 10–17）。

- 已明确专业方案也不是单纯自动绑骨骼，而是骨骼、Mesh、换图、动态层级、修正形状、多方向素材和逐帧动画混合使用（Turn 16–17）。

## 最新问题（尤其 GPT 指出的问题）

以下问题来自最后一次明确评审（Turn 58），应视为当前最优先的质量问题。

### 1. 最大问题：角色图仍偏“精美海报”，不是生产设定稿

当前图更重视漂亮、气氛、版式和展示感，没有充分提供后续 Sprite、立绘、分镜和连续剧情真正需要的信息：稳定轮廓、正侧背结构、发型构造、衣服分层、年龄成长继承及换姿势后的可识别性。

### 2. 年龄感偏大

正式开场设定为 7–8 岁，但图中不少角色更像 9–11 岁。GPT 指出的原因包括五官过精致、身形偏修长、气质早熟、服装像“精致缩小版少年少女”。

### 3. 男女主辨识度不够，仍有模板感

- 男主较像常见“安静漂亮的小少年”，需要增加朴素感、观察者气质和非标准美少年特征。
- 女主的清冷克制方向可保留，但需要更多来自其家乡或个人习惯的视觉记号，避免只是常见的清冷漂亮少女模板。

### 4. 同学 NPC 的真实差异不足

虽然比前版进步，但仍然人人可爱、整洁、精修，像一组“小主角”。欠缺真实班级应有的普通人、活泼/安静差异、家境差异、轻微土气感以及不同亲和档位所对应的气质层次。

### 5. 版式信息密度过高

标题、说明文字、装饰文案和栏目过多，适合展示，不利于制作。生产稿更需要每人独立格、全身比例、正面/3/4/侧背、服装拆解、关键配色和识别点。

### 6. 尚未解决“角色稳定复用”这一核心技术问题

当前图还不能证明可以稳定支持：多场景连续出图、儿童到少年成长、同角色不同动作、正反侧一致，以及游戏立绘/Sprite 的统一。这是 GPT 在最新评审中指出的最关键落地风险。

### 7. 较早但仍未关闭的技术风险

- 自动绑骨骼不等于动作自然；古装长袍、宽袖、披风、长发、飘带会产生关节断裂、露洞、穿插、纹理拉伸、图层错误和纸片感（Turn 10–17）。
- 普通 2D Rig 无法凭空生成侧面和背面信息，转身和出平面动作必须换方向素材、专门转身序列或走视频抽帧（Turn 16–17）。
- 生成式图片即使写了“正交”，仍容易自动加入透视；因此地图地面必须持续按无透视缩放验收，不能把“斜俯视”误写成普通透视插画（Turn 24–30）。

## 建议下一步

### 优先级 1：把童年角色方向稿转成生产设定稿

先不要继续扩展更多角色或制作漂亮群像海报。优先分别制作：

1. 男主童年版 2–3 个精修候选；
2. 女主童年版 2–3 个精修候选；
3. 每个候选至少包含正面、3/4、侧面、背面、全身比例、发型结构、服装分层、关键色和唯一识别点；
4. 明确要求年龄观感为 7–8 岁，而非缩小版少年；
5. 选定男女主后，再设计儿童版到少年版的继承规则。

这与 Turn 58 给出的下一步直接一致，也是解决角色连续复用问题的前提。

### 优先级 2：单独制作同学 NPC 分组稿

不要把所有同学同时做成精致主角脸。可按“普通同学 / 活泼型 / 安静型 / 天赋较突出者 / 第一档普通者”分组，每组先做少量角色，并有意拉开脸型、体型、衣着整洁度、家庭条件与行为气质。原文建议固定 5–7 个核心同龄角色，其余作为背景同学（Turn 41、58）。

### 优先级 3：对一个定稿角色做最小生产验证

角色定稿后，立即验证而不是继续只出概念图：

- 输出正、背、左、右四方向静态图；
- 人工拆件并测试 `Idle / Talk / Wave / Point / Walk`；
- 记录哪些动作骨骼可接受，哪些必须改用 Sprite/AI 视频抽帧；
- 用同一角色在已验收地皮和资产场景里摆一次中远景，检查比例、脚底落点和风格一致性。

这能同时关闭“角色能否稳定复用”和“古装 Rig 到底能承担多少动作”两个长期未验证问题。

### 优先级 4：把已有美术成果整理成可执行资产规范

以 Turn 38 的 Style Bible 为基础，保留已经收敛的规则，但补上实际生产字段：文件命名、画布尺寸、角色高度、门与人物比例、方向枚举、透明边距、锚点、碰撞/遮挡层、光向、色板和导出格式。原文尚未证明这些规则已进入实际引擎资产流程。

### 优先级 5：回到世界地图做一次“旧地图—V0.6”对照整合

在继续扩写城市前，应先把 Turn 50 上传的旧地图内容转成文字清单，并逐项对照 V0.6：中央巨峰、望雷、千湖、东南城、东北湖城、主角村—县城—区域中心的层级分别落在哪里；冲突项应由用户拍板。由于转存缺少图片文字细节，当前不能替用户补定。

### 优先级 6：再补齐尚未拍板的地理项

原文最新仍明确留下：东南五大城名称与核心地貌、东北湖城名称、千湖是否正式为内陆、女主与东北湖城/月岛的关系（Turn 49）。这些适合在旧地图整合后统一决定，不宜脱离原地图继续发散。
