# 角色形象 V1

本目录是一版可继续筛选和进入生产验证的角色设定图，使用内置 imagegen 生成。附件 `sheet-01 / sheet-02` 仅作为旧方向参考，没有沿用其海报式版面。

## 图片说明

- `01-leads-childhood-production-sheet.png`：男女主 7～8 岁精修制作稿。每人包含正面、3/4 侧、发型结构、背面/服装拆层与色板。男主以不显眼的普通村童和观察者气质为主，不画隐藏的空间/自然能力；女主以云安湖城的雾蓝绳结、湖石珠和短披肩形成地域识别，保持偏冷但不高傲。
- `02-teacher-candidates.png`：两男两女共四位老师候选，分别偏自然启蒙、测量/阵法、基础教学和资深综合教学。加入标本箱、量尺、石板、笔记与演示仪等教具，并给出课堂互动小稿，使身份更像长期驻校教师而非侠客或贵族。
- `03-classmate-npc-groups.png`：12 名同学 NPC 分组稿，从左到右为普通、活泼、安静、亮眼、路人感。通过脸型、体型、姿态、发型、衣物颜色、补丁和旧衣尺寸拉开差异；他们是班级生态，不是整齐的主角团。

## 相对旧选型的调整

- 年龄统一下压到更明确的 7～8 岁：短肢、圆脸、较低身高比例，减少“缩小版少年少女”感。
- 从装饰性海报改为浅底制作板：角色分格、同尺度全身、结构拆解、少文字、少背景。
- 男女主保留原方向，但增加可识别轮廓和服装结构，降低通用国风美型感；服装缩短、收袖并露出关节，便于后续 Rig/Sprite 验证。
- 老师以教具、工作姿态、年龄和实用服装强化职业身份，男女均有候选。
- 同学不再统一蓝白配色或同款可爱脸，主动加入普通、土气、旧衣、不同家境与低显眼度角色。

## 本轮生成提示词摘要

共同要求为：温暖手绘幻想乡村、轻东方、克制的墨线与水彩质感、低饱和生活色；制作向浅底设定板；避免强仙侠、贵族华服、武器、魔法特效、宣传海报构图和大段装饰文字。三张图分别聚焦男女主跨视角一致、教师职业动作与教具、以及五组 12 人班级差异。
