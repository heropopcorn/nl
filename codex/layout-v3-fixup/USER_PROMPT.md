之前的初衷是结合此图，实现以下功能：
下面按照如图所示的区域调整整个功能区域
1、元素列表显示当前场景的所有的元素（如果现在没有打开任何的场景，则显示空白或者显示请打开场景），现在，所有的场景中的各项都视为元素，比如，背景图片、人物贴图（人物序列帧）、水流区域以及各项特效等等，全都视为元素（类似于一切皆为对象的意思）
元素列表区域显示类似于unity中的hierarchy区域，可以看到当前场景中的所有元素的列表，点击之后在编辑区域显示这个元素
2、资源列表区域，显示两个tab，默认资源/自定义资源。然后资源下方也有分类：背景图、树木、角色、房屋，点击可以放置到场景中，每个场景的背景图只能有一个，点击添加背景图，弹出提示，已经有背景图，是否替换
自定义资源需要支持上传，自定义其余资源上传之后
3、每个元素都需要有自己的属性，其中，实物比如人物、背景图、树木都需要有图层高度信息，如果是人物或者树木等等，可以有路线属性（在属性面板可以添加路线、设置路线的速度、以及是否显示等等）、水流区域也需要有图层信息，然后，属性中需要有范围，可以添加不止一个范围区域，除了水流，还需要有雾气这种(后续版本迭代还会有其他的特殊的东西)
还有一种就是现有的场景中，扣除一块区域单独设置显示层级，这个也是一种特殊的元素，这个元素可以在左侧列表看到，也可以点击背景图，在背景图的属性面板看到当前背景图有几块区域
4、章节/场景区域则类似于project的区域布局，在最下方，然后左侧是project的树状图列表，右侧则是类似于文件夹区域现实，最外层是章节，每个章节点击进去就是场景了
5、属性区域就是显示点击的各个物体的属性的面板，上面说的给人物增加路线，也是在这个面板中，点击增加路线，则可以在编辑区域画路线
6、工具区域，则类似于unity的工具，有移动、缩放、旋转、镜像等等一系列工具
7、最上方，有一排类似于软件的按钮，文件、编辑（暂时先保留这两个），比如文件中可以新建章节、场景以及一系列的元素（在hierarchy中也可以新建各种元素，在project也可以新建章节、场景）
