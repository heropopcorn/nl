## 2. 总气质

- 温暖手绘幻想乡村，生活化、可居住的魔法村感。
- 高质量 2D 经营 / RPG / 农场风，**非像素**。
- **轻东方**：带一点东方味，不要强中式（少飞檐、宫灯、皇宫感）。
- 可兼容少量西式 / 泛幻想乡村元素；默认中庸融合，不单一强中式。
- 不要：写实、照片感、3D 渲染感、厚重概念插画、风格乱飘。

---

## 3. 镜头与两类出图

**地面地图（跟 A）**
- 严格正交俯视 / top-down orthographic
- 无近大远小、无透视缩放
- 服务可走路、可摆建筑、可做视频演出
- 元素：草地、石路、河/桥、农田、空地、树等

**独立资产（跟 B）**
- 固定斜俯视 / top-down isometric（orthographic oblique）
- 透明底优先，或纯黑底方便抠
- 统一角度、统一比例、统一材质笔触
- 已出现类型：蓝顶民居、橙顶市集、藤蔓圆塔、水车、风车、井、桥、告示牌、灯、树、菜地、畜栏、推车、花草石块等

默认柔和白天光、轻阴影；除非要求，一般不加人。

## 4. 制作管线（和风格配套的流程）

1. ChatGPT 网页出静图（场景 / 人物）→ 你确认  
2. 人物图 → 视频模型走路（左 / 前 / 后；右用左镜像）  
3. 抽帧选帧 → 可拼精灵图（imageHandle `/spritesheet`）  
4. Godot 做流水等画面效果  

可复用长文出图指引：`chatgpt-followup-image-prompt.md`（含主提示词、配色、负向词、地图/资产模板）。
