一、整体人物设计原则

先定这一批人物的共通原则，避免后面风格跑偏。

1. 角色不要“仙气太重”

因为前期是普通村庄、基础学堂，所以大家应该更接近：

干净

朴素

有辨识度

稍带幻想气质

而不是：

华丽仙侠

满身飘带

一眼绝世高手

王公贵族既视感

2. 儿童期与成长后要能连续演化

这批人不是只出一个“成年定妆照”，而是要能从：

7～8 岁

10～12 岁

14～16 岁

17～18 岁

一路长上去。

所以设计时要保证：

小时候的轮廓、气质、颜色偏好，长大后仍然能认出来。

3. 主角前期不要视觉外挂

因为主角表面只是：

五行都有一点，没有单一突出，表象第二档。

所以外观上不要设计成：

异色瞳

一身神秘纹路

天生发光

一眼稀有血统

隐藏属性“空间 + 自然”前期只能通过很细的感觉来埋。

二、主角（男主）形象设计
1. 人物定位

性别：男

身份：普通村民家庭独生子

开场年龄：7～8 岁

表面天赋：常见五行都有一点亲和，但无单一突出

隐藏属性：空间 + 自然（前期不显）

他的核心感觉应该是：

看起来并不抢眼，但很耐看；第一眼普通，越看越顺。

这很适合你这条教学成长线。

2. 儿童期外形（7～8 岁）
外观关键词

清秀

干净

普通但顺眼

不瘦弱，也不是特别壮

有一点安静观察型的感觉

脸

脸型偏清秀，轮廓柔和

眼睛不需要很大，但要有“看东西很认真”的感觉

眉眼温和，不凶

表情经常是“在看、在想、在观察”

发型

我建议：

黑发，稍微有点蓬松，前额碎发，自然、不精致过头。

儿童期不要高马尾、不要复杂发冠。

可以是：

短发偏中长

后面略长一点

有一点乡村孩子不太讲究但很干净的感觉

服装

前期要非常普通。

建议：

米白内衫

灰蓝 / 青灰短外衣

深色裤子

布鞋

小书袋 / 简单背包

颜色不要太艳。

色彩倾向

主角前期建议用：

米白

灰蓝

浅青

木棕

少量草绿色点缀

理由是：

不明显偏某一元素

比较“均衡”

和空间 / 自然后期都不冲突

3. 性格气质（前期）

不是热血大嗓门型。

更像：

观察细

反应不慢

不爱抢风头

有自己的好奇心

看起来没那么惊艳，但老师会觉得“这孩子挺稳”

和那种“主角从小最耀眼”的路线区分开。

4. 成长后外观演化
少年期（12～14 岁）

个子长高

轮廓更清晰

眼神更沉稳

衣服变得更利落，带一点学堂气质

可加入简单的腰带、护腕、小型工具袋

青年期（16～18 岁）

保留清秀感，但更挺拔

面部线条稍成熟

服装仍偏朴素理性，不要过于华丽

可逐步增加：

阵纹笔袋

简单测量工具

空间相关的小挂件（很克制）

自然观察记录册

5. 主角的“隐藏感”怎么体现在视觉上

前期只能轻轻埋：

空间线索

看阵图、地图、摆件时特别专注

动作习惯整齐、位置感强

视觉构图里常站得很“正”

自然线索

比别的孩子更常看树、草、水、土

和环境相处很自然

不是“万物亲和”，只是显得更能注意到周围状态

不要让他一出场就有“自然灵光围绕”之类效果。

三、女主形象设计
1. 人物定位

女主来自：云安

云安定位：东北五大城市，迷雾大湖西岸，湖心有月岛

女主不是一出场就神秘到离谱的人

她首先应该是：

来自大城市、见识更广，但仍是正常成长路线里的学生

她和主角的对比重点不应该是“谁更神秘”，而是：

主角来自东南乡村，女主来自云安这样的名城。

2. 外观关键词

清冷但不冷漠

聪明、克制

有一点湖城气质

稍带雾感、月色感

比主角更精致一点，但不是贵族大小姐

3. 脸与气质

脸型偏秀气

眼神清亮、安静

不用特别甜，偏理性一点更好

讲话应给人一种：

她平时不吵，但想法很清楚

4. 发型

建议两套都可行，你后面选：

方案 A：半束发

黑发或深墨发

上半部分束起

下半部分自然垂落

整体轻盈，利落

方案 B：单长辫 / 双侧低束

更适合学生气

也适合 sprite 识别

我个人更推荐：

半束发 + 少量发饰

5. 服装与色彩

因为来自云安，可以带一点：

雾白

淡青

湖蓝

月灰

少量银色细节

服装要比主角更整洁一点，但不能夸张。

前期如果出儿童版，也不要直接穿“云安贵族校服”，而是：

干净的学生式长上衣

层次分明但不复杂

带一点湖城审美的细节

6. 女主和“月岛”的关系

目前不建议把她直接设成“月岛出身”。

视觉上也不要搞成：

月岛圣女 / 神秘继承人

更建议她只是：

从小在云安长大

对湖、雾、月岛这些事物很熟悉

这构成她气质的一部分

这样更适合教学成长线。

四、老师形象设计（先定一位核心老师）

你说老师不是重点，那我先定一个核心老师模板，足够支撑前期剧情。

1. 人物定位

联盟派来

表面只是普通支援教师

实际是“隐藏教学大师”

特长不是战斗，而是：

特别会教 7～12 岁这个年龄段的孩子

2. 形象方向

我建议不要太老，也不要过分仙风道骨。

年龄感

外表 35～45 岁左右

正值经验成熟期

性别

这轮我先给你设计成：

男老师

因为主角、两个伙伴、女主以后人物群里，先有一个稳定男老师会比较好。
如果你想，也可以后面再补一个女老师。

3. 外观关键词

温和

克制

不张扬

看起来像读书人 + 实操教师结合

不像战神，更像很稳的教书先生

脸

轮廓端正

眼神平静

说话时不会压人

偶尔会笑，但不是特别外露

发型

黑发夹少量灰

简单束发或低发结

不需要高冠

服装

深青 / 墨蓝长衫式外衣

内层米白

腰间有教学用的小器具袋

可以带一块联盟教师牌，但不夸张

4. 角色感觉

学生会觉得：

“这个老师挺会教，讲的东西我能听懂。”

大人会觉得：

“他不像普通乡村先生。”

但不会第一眼看出他很厉害。

这就够了。

五、两个主要同伴

这两位目前只做“可长期使用的基础形象”，先不写复杂身世。

你已经定了：

两个比较要好的伙伴，天赋都不错，属于第三档。

那他们在视觉和气质上，应该与主角形成清晰区分。

同伴 A
1. 定位

主角的近友之一

第三档

比主角更早显得“有天赋”

性格偏外向一些

2. 外观关键词

活力

直率

健康

反应快

3. 外形

可以设成男生

发型略短、更利落

眼神更亮

体态更有行动感

4. 服装色彩

建议偏：

青绿

土黄

暖棕

这样比较贴近乡村，也容易和主角区分。

5. 作用

这个角色更适合承担：

拉主角一起跑

更快进入元力练习状态

前期在“显性天赋”上比主角更亮眼

同伴 B
1. 定位

主角的另一位近友

也是第三档

相比 A，更稳、更细致

可与主角形成“安静型对照”

2. 外观关键词

稳

整洁

认真

可靠

3. 外形

这里可以做两种方向：

方案 1：男生

这样主角会有三个从小一起长大的男孩小团体。

方案 2：女生

这样前期同伴层就有男女混合结构，人物互动会更自然。

我更推荐方案 2。

因为你后面还有女主来自云安，如果前期村里就有一个关系熟悉的女孩同伴，人物群会更均衡。

4. 服装色彩

建议偏：

浅棕

米白

柔和蓝灰

气质更安静一些。

六、目前最推荐的人物组合

如果你想让我先给一个最顺的搭配版本，我建议是：

1. 主角（男）

普通村民家庭

第二档表象

隐藏：空间 + 自然

2. 两个近友

伙伴 A：男，第三档，外向、行动快

伙伴 B：女，第三档，稳、认真、细致

这样前期“村里小团队”会很好用。

3. 女主

来自云安

与主角不是从小同村

后期在更大舞台相遇 / 深化关系更自然

4. 核心老师

男老师

隐藏教学大师

温和、会教、长期观察主角一代

这个组合既简单，又能长期展开。
