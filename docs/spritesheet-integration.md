# 序列帧制作与自定义分类

入口：左侧资源库 → 自定义资源 → 制作序列帧。也可从“更多资源”大窗口打开。

1. 在资源库或制作窗口输入新分类名称，点击“新增分类”。名称不可为空、不可重复，最多 100 个分类。
2. 上传或拖入视频，按 FPS 或时间间隔抽帧，最多 120 帧。视频本地解码，不上传外部服务。
3. 点击帧可查看，勾选启用、拖动排序或前移／后移；按需对选中帧或所有启用帧去除底色。
4. 设置列数、帧内边距、帧间距、格宽高和对齐方式，合成并预览图集。变更帧或合成参数后必须重新合成，避免保存过时结果。
5. 选择自定义分类、设置播放 FPS，保存到自定义资源。PNG／JSON 也可单独下载。
6. 关闭制作窗口，在对应自定义分类点击资源放入 2D 场景。序列帧自动播放，不需要场景时间轴。

分类与保存的图集、精确帧矩形、FPS 随项目保存在本机数据库，并进入项目 JSON／备份。旧项目没有分类字段时自动使用空列表。普通图片也可上传到新分类（作为可放置的图片道具）。原有背景／音频／模型等类型入口继续保留。

限制：视频最多 80MB；保存的单张 PNG 最多 20MB；总资源最多 100MB；图集单边最多 8192，总像素最多 16,777,216；最多 200 项自定义资源。浏览器需能解码相应视频格式。背景去除使用边缘颜色泛洪，不是 AI 抠图；复杂背景需要其他工具处理。透明边缘裁切默认关闭，避免逐帧重对齐引起抖动。

制作中的抽帧草稿暂不持久化，关闭会提示；已保存资源保留。没有迁移原站的 Supabase 登录和云端项目管理，使用本项目原有登录与本机项目保存。

## 来源与适配

核心算法移植自 `/workspace/imageHandle` 远端 `main`，提交 `d87aaa2`（序列帧实现来自 `eae4cca`）。源仓库工作区保持在原提交，未切换或修改。

- `packages/spritesheet/spriteFrames.ts`：抽帧参数、时间采样、帧排序。
- `spriteExtract.ts`：浏览器视频抽帧；增加取消清理和内存限制。
- `spriteCutout.ts` / `matting.ts`：边缘泛洪去底与裁切；调整 URL 生命周期为调用方管理。
- `spritePack.ts`：图集排版及 PNG／JSON；增加图集尺寸上限。
- 制作面板重新适配本项目布局；保存取代原站云端存储。
- `packages/core/sprite-frame.ts`：按实际帧矩形播放，支持帧间距与未填满末行；旧资源继续按行列切分。

验证：单元测试覆盖时间采样、图集排版、旧项目兼容、分类引用、帧边界及尺寸限制；浏览器测试使用真实 WebM 抽帧并验证去底、排序、保存、导出、自动播放和刷新恢复。
