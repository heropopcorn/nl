# 多影棚导演台 · 背景与多边形迁移版

独立 Web 工程，保留 `video_game/` 的 Godot 编辑器、数据和部署配置。新工程不会读取或改写旧场景。

## 启动

需要 Node.js 20.19+。在仓库根目录：

```sh
npm ci
npm run build
npm start
```

打开 `http://127.0.0.1:4173`，使用现有管理员账号登录。沿用旧工程的密码哈希与认证逻辑，没有新增明文密码。生产运行设置 `NODE_ENV=production` 和至少 32 字符的 `AUTH_SECRET`，并通过 HTTPS 反向代理提供服务。可设置 `ADMIN_USERNAME`、`ADMIN_PASSWORD_HASH`、`PORT`、`HOST`；多实例认证及限流需另行部署设计。

开发：`npm run dev`，地址 `http://127.0.0.1:5173`。**开发服务器不带登录，仅绑定本机；不要对公网开放。** 本次未修改线上部署。

## 已接通

- React 导演台：元素列表、带缩略图的背景资源、属性、镜头列表和主时间轴。
- PixiJS 2D / Canvas 动态图形影棚，共用整数帧时钟；示例为村庄、学校、五行动画。
- 镜头复制/删除、名称/时长/字幕、角色重命名和线性路线起终点；撤销重做。
- 本机自动保存、校验后的 JSON 导入导出。新存储键 `yuanli.web-director.v1` 与旧工程隔离；登录不等于云端保存。
- 预览缩放和中键平移独立于场景参数；逻辑坐标左下角为零点。
- 当前帧 PNG，以及从当前帧起最多 30 帧的 PNG ZIP 序列（含帧率和项目快照）。使用独立渲染器，不污染预览状态；支持取消。不是 MP4，也不是全片批量导出。
- 环境元素：雨滴及落地涟漪、飘雪、漂移雾气、带流动纹理的水域，以及背景遮挡块；支持矩形和逐点绘制的多边形区域。
- 元素可重命名、禁用、删除、设置层级；天气可设置强度、速度、风向和随机种子，每个元素支持最多 12 个范围。
- 早晨、中午、傍晚、夜晚，以及夜间环境亮度与月光强度。
- 角色、天气和遮挡块共用深度排序。层级优先，同层按左下角坐标系的 Y 从高到低绘制；雨雪按落地点参与排序。遮挡块默认以矩形底边排序，可指定遮挡横线。
- 选中环境元素时显示范围及自定义横线；这些编辑辅助线不进入 PNG 导出。
- 村庄、村庄学校各 12 个时节背景，时节滑杆/下拉框、背景缩略预览；默认/x2/x4 清晰度选择。

## 环境功能操作

选中一个 2D 镜头，在左侧「添加环境元素」选择雨、雪、雾、水流或背景遮挡块，右侧编辑属性。范围 X/Y 表示背景左下角逻辑坐标，宽高同样使用逻辑像素，范围不能超出 1536×1024；无效输入会被拒绝并在状态栏提示。新增水域和遮挡块默认是局部矩形，需要调整到实际位置。

矩形仍可通过数字编辑。点击「重绘范围 N」替换已有范围，或「绘制新增多边形」添加范围；左键逐点，点击首点、按 Enter 或点击「闭合范围」完成。Backspace /「撤销顶点」回退一步，Esc /「退出绘制」丢弃尚未提交的草稿。最少 3 点、最多 128 点，拒绝自交、零面积和越界轮廓。完成后保持多边形工具选中，可继续画下一块；中键平移不中断草稿。切换选中元素或镜头会取消未提交草稿。多边形的数字框显示只读包围盒。选中元素后用工具条「顶点」拖动多边形顶点或路线点；「自由套索」按住拖动，松手时按约 8 逻辑像素简化并闭合。

让房屋遮挡雨滴：添加覆盖房屋的背景遮挡块（恢复这部分背景图像），再设置它与雨、角色的层级或自定义横线。高层级总在前，同层级根据地面位置排序。完整背景是一张平面图，不能自动识别房屋。可沿屋檐绘制多边形，避免矩形块把周围地面一并覆盖。全屏雨不会作为最终叠加层强行盖过遮挡块。

雨水强度控制下落速度、粗细和水花大小；雨水密度单独控制落点数量，公式与旧导演台相同（每单位面积 150 + 9000·密度⁴，单区最多 1280 条流）。为控制渲染开销，实际每区最多取 320 条流，每条流可同时产生多个雨滴或水花，并非画面雨滴总数上限。雨滴从画面上方落到区域内的随机落点，不被区域裁切；每轮重新选落点。水平风把雨滴从竖直吹到最多 60°，纯上/下风只改变下落速度。

镜头风效提供八个方向、0–1 风力和 1×–20× 风速。风丝沿固定曲线显现、尾部消退，两端收尖，约四分之一在末端带渐隐短钩。风力零仍有弱风丝，取消「启用风」完全关闭。这是旧着色器的画布对应效果，不是逐像素移植。打闪只在有雨时出现。

水域可以画多条流向线。每一点的流向是各条线切线按距离平方反比加权后的合力；两条相反的线抵消时跟随更近的一条。没有流向线时使用属性中的二维基础流向（X 正值向右、Y 正值向上）；未设置向量的旧 Web 数据仍使用水平方向。水域可以共边，面积重叠时范围标红，并禁止自动保存、手动保存和播放，修正后才会落盘。

环境效果按镜头局部帧和固定种子直接计算，速度为零时冻结，暂停时不自主播放；跳帧和序列导出共用相同合成路径。修改参数不会改变视图平移、缩放和时间轴位置。雾、水域按区域底边或指定横线整体排序；雨雪按落地点排序。水流是程序化流纹，雪是飘落粒子，不包含流体模拟、积雪或刚体碰撞。角色路线可以选择「遇到区域停止」，并与镜头的「全局区域碰撞」同时生效。

旧 Web v1 项目缺失的环境、光照、角色层级和时节字段会自动补默认值；旧矩形无需转换。Godot v2 场景及早期 `scene_layout.json` 可从文件菜单旁导入，不直接运行 Godot 工程。项目结构版本保留 v1（向后兼容的可选字段扩展）。负的风力值仍表示旧数据里的向左风。

导入时一并选择章节索引、资源索引和图片，然后在确认面板检查图片绑定；也可重新选择整个旧工程目录保留相对路径。同名图片不明确时必须手动指定。导入按原章节和顺序追加，可一次撤销，不覆盖已有内容。空白底色、自定义道具实际尺寸、蓝衣角色、二维水流方向均会转换；旧 world 路线碰撞转换为「区域碰撞停止」，不是旧物理引擎的完整复刻。原始 JSON 保存于镜头的 `legacySource`；烘焙道具、旧位图水域、相机扩展仅保留数据并提示，尚不参与渲染。

顶栏「本机备份」可创建和恢复快照。自动备份至少间隔一分钟，最多五份且有容量上限；恢复前先备份当前项目。IndexedDB 是主存档；小项目另有同步临时日志，刷新时优先恢复尚未提交的最新编辑。读取失败时尝试本地镜像和历史备份。保存期间离页会提醒，尤其大项目应等待保存完成。清理浏览器数据仍会丢失这些本机副本，不能代替导出文件。F3 开关碰撞调试区域与角色脚底标记，辅助线不会进入 PNG/MP4。

## 背景时节与清晰度

右侧「背景时节」选择原图或春夏秋冬各初/中/晚，共 13 个档位。时节随镜头保存，滑杆切换静态图片，不会自动随镜头播放时间推进；昼夜光照与时节独立。资源缩略图跟随当前时节。替换背景族会提示确认，原有元素和路线坐标保持不变。不同生成时节图片若构图细节有差异，需人工复核遮挡轮廓。

右上角「背景分辨率」是会话显示选项，不改项目坐标或存档；当前 PNG 输出也使用此版本，但输出画布仍为 1280×720。x2/x4 只代表文件标签，选项显示图片实际宽高。版本不存在则置灰，切换到缺少该版本的时节/镜头时回退默认。当前仓库未提供 x2/x4 图片，因此默认不可选；本功能不会生成或自动放大背景。

在原图旁放置 `protagonist_village_x2.png` / `_x4.png`；时节图放在 `video_game/art/backgrounds/seasons/`，例如 `village_school_winter_mid_x4.png`。运行 `npm run prepare:assets`（开发和构建也会运行）重新生成 `public/assets.json`，再刷新页面；线上需重新构建部署。清单只列出存在的 PNG，通过文件头读取实际尺寸，不依赖文件名推算倍率。新增版本必须与原图保持相同构图；宽高比不一致时会映射并铺满逻辑画布，可能拉伸。

所有背景共用左下角原点和 1536×1024 逻辑画布。实际图片像素为 `(逻辑X × 图片宽/1536, 逻辑Y × 图片高/1024)`。同尺寸 x2 不改变范围，更大图片按真实 X/Y 比例映射。角色、天气、多边形和遮挡线不改坐标；裁片始终取当前背景版本。背景按需加载，过期加载结果不覆盖最新选择；加载中或失败时禁用输出，避免误导出旧画面。序列导出逐镜头等待资源，并记录所用版本及真实尺寸。图片尺寸仍受浏览器/GPU 纹理上限约束。

## 分层

`packages/core`：版本化文档、输入校验和帧定位；`packages/studios`：影棚接口、2D/动效实现和统一字幕合成；`apps/director-web`：交互、持久化、输出和认证入口。影棚没有独立播放时钟，任意帧直接求值，不依赖此前播放历史。

2D 使用固定 1536×1024 逻辑坐标，画面适配到 1280×720 输出。已支持布景版本快照和从快照新建镜头；内置角色为静态占位图，自定义角色支持序列帧。

## 编辑、章节与出片

- 工具条：移动（保留抓取点，方向键 1/10 像素，按住 Shift 吸附 8 逻辑像素）、缩放（拖四角等比，锚点在脚底，Ctrl/Cmd+T）、旋转（拖外圈，Shift 吸附 15°）、镜像、顶点、画路线、水流导线、自由套索、矩形区域。
- 停止时可用 WASD 走位预览。走位只改变画面，不写入路线或起点；再次播放会回到已保存路线。
- 资源库分默认/自定义。可上传 PNG、JPEG、WebP、音频和内嵌纹理的 GLB。内置角色有农夫和蓝衣农夫。自定义角色可设序列帧的列、行和 FPS。
- 底部「章节 / 场景」可新建、改名、删除、搜索，以及章节和场景的上移/下移。场景卡片显示当前 2D 镜头的背景缩略图，空白画布用中性色块。删除章节会连同其中的场景和镜头一起删除，并至少保留一个镜头。
- 右侧可把当前镜头保存为布景版本，再从该快照新建镜头。快照不会跟着后来的改名变化。
- 空白画布使用同一套 1536×1024 逻辑坐标和中性底色，不切换时节图。
- 音轨按全片帧摆放，播放时跟随时间轴；导出 MP4 时由本机 FFmpeg 混成 AAC。
- 3D 镜头使用 PlayCanvas，可放立方体、球体、圆柱、平面和 GLB，并调整相机。

降雨的每个范围可以单独关闭水花；未单独设置时跟随整场雨的水花开关。

## 尚未迁移

详细核对见 [迁移审计清单](migration-audit.md)。主要导入参数问题已修复；烘焙道具、旧位图水域、相机扩展仍待运行时迁移。不能将当前版本视为旧数据的无损迁移工具。

风丝仍是画布近似，未逐像素复现旧着色器。每个降雨区域实际最多取 320 条流，旧公式计算上限为 1280。旧导演台没有四方向行走序列帧，也没有相机关键帧，不列为漏迁。普通图片元素在网页版选中后即可画路线，旧说明里的「通用路线」当时还未开放。新版仍不是 Godot 导演台的完整替代品。
