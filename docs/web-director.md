# 多影棚导演台 · 实时场景编辑
当前优先做场景布置与环境效果。界面暂不提供时间轴、播放按钮、时长、音轨编排、定时字幕和视频导出入口；已有项目的这些数据仍保留，没有删除。底部改为章节、场景和布景卡片。

## 启动与数据
需要 Node.js 20.19+，仓库根目录运行：
```sh
npm ci
npm run build
npm start
```
生产页面为 http://127.0.0.1:4173，沿用现有管理员认证与密码哈希。生产设置 NODE_ENV=production、至少 32 字符的 AUTH_SECRET，并通过 HTTPS 反向代理提供服务。可设置 ADMIN_USERNAME、ADMIN_PASSWORD_HASH、PORT、HOST。本轮未改线上部署。

开发使用 npm run dev，绑定本机 5173。开发服务器没有登录，不要暴露公网。数据保存在浏览器本机，不是云端存档。

## 添加即展示
左侧「添加环境元素」可添加降雨、降雪、雾气、水流、背景遮挡块和雷电。环境按独立的临时预览时钟运行，无需点击播放。添加雨时立即出现雨滴，添加雷电立即闪光，后续按间隔重复；雷电不依赖降雨，目前只含视觉效果、不含雷声音效。

改名称、强度、碰撞、区域等不会重置其他效果的时钟，也不会移动角色或重新居中画布。切换布景或重新开启某个效果会重启相应预览。动画时间不写入项目，不触发自动保存或撤销历史。角色仍可通过 WASD 走位预览或编辑起点；不会因天气时钟自动走完路线。

旧项目的全局雷电开关也保留，并可独立开启。水流速度为零时静止；强度为零不显示效果。水面使用从旧 Godot water_flow 着色器移植的双相连续流动、沿流向卷积高光和底图折射，不再绘制随机移动短线。流向导线生成二维方向场，沿弯曲导线流动；没有导线时使用基础 X/Y 流向。效果依赖 WebGL；不支持时显示加载错误，不静默回退成短线。

## 环境元素的隐藏与删除
每个环境元素在左侧列表都有「隐藏/显示」和「删除」按钮。选中后右侧顶部也有「删除当前环境元素」。隐藏保留参数，删除移除整个元素及其区域，均可撤销。

每个元素最多 12 个区域。在右侧「区域列表」中：
- 「选中区域 N」高亮该区域。
- 「编辑区域 N 顶点」显示控制点，可单独拖动矩形或多边形顶点。
- 「重绘区域 N」用套索替换此区域，不修改其他区域。
- 「删除区域 N」只删除这一块，最后一块也可以删除。零区域元素保留在列表中，不产生效果，可继续添加区域。
- X/Y/宽/高可精确编辑，多边形也可整体平移或等比于包围盒各轴缩放。
- 选择区域后，移动、缩放和旋转只作用于该区域；直接拖动范围内部可选择并移动该区域。
- Delete 在已选择区域时删除该区域，否则删除选中元素；绘制中的草稿不会被 Delete 误删为整个元素。

不规则多边形仍需至少三个顶点，不能自交、退化或超出逻辑画布。水域可以共边，面积重叠会标红并阻止保存，需要调整范围后再保存。

## 多边形套索
默认套索为逐点绘制：单击放一个点，鼠标松开不会闭合。可以移动鼠标观察下一段。
- 点击首点、双击或 Enter 完成闭合。
- Backspace /「撤销顶点」撤回上一个点。
- Esc /「取消绘制」丢弃未完成草稿。
- 中键拖动画布不会结束草稿。
- 完成后工具保持选中，可继续绘制下一块。
- 切换场景或元素时丢弃当前草稿，避免把旧草稿写入新元素。

矩形区域仍是按住左键拖动、松开完成。它与逐点套索是不同工具。

## 画布、层级与背景
移动保留抓取点；图片缩放拖四角；旋转拖外圈，Shift 吸附 15°。V 回到移动，Ctrl/Cmd+T 缩放，方向键微调。中键平移、鼠标位置滚轮缩放与场景数据独立。F3 显示区域碰撞和角色脚底，不进入 PNG。

整数层级优先，同层按脚底/雨滴落点排序；可用独立背景裁片遮挡角色或雨，并设置遮挡横线。图片不能自动识别房屋，需人工圈出裁片。

所有布景使用 1536×1024 逻辑坐标，左下角为 (0,0)。两套背景各有春夏秋冬初/中/晚档位。时节是手动静态选择，不随预览时钟变换。分辨率默认/x2/x4 依照实际文件尺寸映射；缺少的版本置灰，不会自动生成高清图。当前帧 PNG 仍输出 1280×720。

可在原图旁添加同构图的 _x2.png / _x4.png 后运行 npm run prepare:assets 再构建。不同宽高比会铺满逻辑画布，可能拉伸。坐标不随分辨率标签改变，裁片取当前实际版本。

## 导入、备份和输出
Godot v2 及早期 scene_layout.json 可从顶栏导入。提供章节索引、资源索引和图片后检查绑定；同名图片需明确选择，目录导入优先按相对路径匹配。旧 world 路线碰撞转换为「区域碰撞停止」，不是完整旧物理引擎。原始 JSON 保存在 legacySource。烘焙道具、位图水域和相机扩展仍待运行时迁移，详见 [迁移清单](migration-audit.md)。

「本机备份」最多保留五份且有容量上限；自动快照至少间隔一分钟，支持手动创建和恢复，恢复前先备份当前项目。小项目临时日志防止即时刷新丢失修改；大项目保存期间离页有提醒。清理浏览器数据会删除本机副本，请定期导出项目 JSON。

「保存当前帧 PNG」保存点击时的动态画面，不包含套索、选框、区域控制点或调试线。旧视频编码模块和存档字段仍保留以备后续迭代，当前界面不开放时间轴或 MP4 操作。
