# Godot → 多影棚迁移核对（2026-09-28）

范围：对照旧 `director_desk.gd`、`director_scene_model.gd`、`scene_repository.gd`、天气控制器/着色器，与当前 Web 的数据转换、编辑器、渲染及测试。不是“入口存在即迁移完成”，也不是旧工程所有脚本的逐像素等价证明。已在风丝修复后继续补齐下表中的导入问题、备份恢复和碰撞调试；剩余扩展字段明确标为待迁移。

## 本轮风丝修复

旧 Web 将每帧可见曲线的两端重新拟合为二次曲线，导致生长时曲线整体形变；短钩依附移动端点。现在使用每周期固定的完整采样曲线，仅改变头尾显隐，短钩固定并渐隐，细线两端收尖，增加暗边和暖色线芯。方向沿屏幕八方向，绝对帧决定结果，跳帧及导出无需积累播放状态。速度为零冻结；与旧着色器一致，风力零仍有微弱风丝，取消「启用风」才完全关闭。

仍非旧 shader 逐像素移植：当前使用 42 个确定性候选风丝，而非旧 shader 的五层空间网格、平行细划痕及轻微呼吸形变。

## 已实现但存在差异

- 雨流候选数使用旧公式，上限 1280，但实际取样流上限 320（`RAIN_DRAW_CAP`）。每条流可能同时产生多个雨滴/水花，不能将 320 描述成实际画面雨滴总数上限。
- 打闪已移植旧事件随机偏移的双闪包络，绝对帧可重复；闪电形状、水流、雾、昼夜和风丝仍为 Canvas 近似，并非旧 shader 完全一致。
- 旧路线 world 是世界碰撞语义，新版 stop 检查启用的区域并停止，不能直接宣称物理行为等价。
- 背景季节是手动选静态档位，不随全片播放时间自动推进；高清切换不改变固定 1280×720 输出尺寸。当前没附 x2/x4 素材，置灰不属于功能缺失。
- 旧版没有四方向角色动画或相机关键帧，不列为漏迁；自定义序列帧是新版能力。

## 仍需补的验收

1. 新增 `legacy-migration.test.ts` 和 `legacy-repairs.spec.ts` 已覆盖 world 路线、空白背景、非正方形资源、多章节、重复文件名、备份恢复和 F3 导出隔离。仍需用户真实历史工程的完整美术验收。
2. 最大雨量和风速下的长时间预览、导出及低性能设备表现；当前自动化不构成性能承诺。
3. 同构图但尺寸不同/相同的 x2/x4 素材实图检查；时节构图变化仍可能需要人工调整遮挡轮廓。
4. 与旧版同场景录像并排核验水流、风丝和昼夜观感；单元测试无法代替美术验收。

结论：已修复主要导入阻塞和参数丢失问题。剩余重点是烘焙道具、旧位图水域、相机扩展的运行时迁移，以及旧物理/着色器的行为等价性，不能标记为完整替代旧导演台。
