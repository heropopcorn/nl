# 背景分辨率版本

右上角分辨率选项适用于编辑、播放及暂停预览。默认使用原图；x2/x4 是版本标签，不是尺寸倍率。不存在的文件置灰。切换季节或背景时，如果所选版本不存在，自动回退默认图。

## 文件约定

在原图同目录放置 PNG：

- 原图：`protagonist_village.png`
- x2：`protagonist_village_x2.png`
- x4：`protagonist_village_x4.png`

时节版本同理，例如 `seasons/village_school_winter_mid_x4.png`。
上传的场景背景使用该场景数据目录中的 `background_x2.png` 和 `background_x4.png`。空白画布也按其实际文件名追加后缀。
内置资源加入文件后需重新导入并导出网页，线上不会自动读取开发机新文件。本功能不生成高清图片，也不自动放大原图。

## 坐标与范围

图片像素坐标原点在左下角，X 向右、Y 向上。选中背景时显示原点。悬停分辨率选项可查看实际图片尺寸。

背景共享原图的逻辑画布。版本的实际宽、高分别决定纹理到画布的映射，不根据 x2/x4 标签推断倍率。因此切换时角色、路线、水域、降水范围、裁片以及遮挡基准线保持相对构图不变；底图裁片使用当前版本的完整清晰度。

例如原图 1536×1024：同尺寸 x2 不改变像素范围；3072×2048 版本的对应像素范围为原来的两倍。若比例不同，X/Y 分别映射并铺满原图画布（可能拉伸）；推荐提供构图、宽高比一致的高清版本。

旧存档仍使用左上角归一化 UV，这是兼容性存储格式，不直接改写已有点。对外像素接口 `world_to_background_pixel` / `background_pixel_to_world` 使用左下角坐标。角色速度、工具偏移等继续使用原图逻辑单位，因此改变清晰度不会改变播放节奏。

分辨率是当前会话的显示选项，不修改场景存档。重新启动默认使用原图。导演台加载高清版本不再执行旧版的 2048 像素降采样限制；可用上限仍取决于浏览器/GPU。
