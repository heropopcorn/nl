# 导演台 Layout V3 使用说明

降水遮挡：雨滴与水花遵守降水区域的显示层级。同层时按落点的纵向位置与角色、房屋脚底排序，屋后的雨被房屋遮挡，屋前的雨显示在前。背景图片中画死的房屋需要先创建底图裁片并设置层级，才能作为独立遮挡物。

导演台用于在 Godot 运行时搭建并预览短镜头。打开 `video_game/project.godot` 后按 **F5**；桌面和 Web 使用同一套全中文界面。数据保存在 `user://director_desk/`，浏览器中对应本站 IndexedDB，不是云存档。

## 工作区布局

V3 按桌面创作软件划分为七个区域：

- 顶部菜单栏：`文件`可新建章节、场景、角色、水流和底图裁片，也可上传资源和保存；`编辑`提供撤销、重做和删除所选。
- 左上元素列表（Hierarchy）：列出当前场景的背景、底图裁片、普通元素、角色、水流和天气。没有场景时会提示先从 Project 打开场景。
- 左下资源列表：`默认资源 / 自定义资源`两页，按背景图、树木、角色、房屋分类。
- 中左工具条：移动、缩放、旋转、矩形水域、套索水域、底图裁片、路线和镜像。
- 中央主编辑区：摆放、选择并预览实际场景。
- 右侧属性区（Inspector）：属性随 Hierarchy 或画布当前选择变化。
- 底部 Project：左侧选择章节，右侧显示章内场景。

## 元素选择与属性

场景中的各项都作为元素出现在 Hierarchy：背景图、角色、普通图片、水流范围、天气和底图裁片区域。点击左侧条目会同步选中画布对象，并在右侧显示该类型的属性；点击画布上的对象也会反向选中 Hierarchy。选中普通元素、角色、水域或底图裁片后，可点 Hierarchy 标题旁的“重命名”，也可双击条目名称；新建的同类区域会自动带序号。

背景是单例。选择背景时 Inspector 会列出它包含的底图裁片区域；点击区域名可切换选择。普通元素可以设置整数层级、缩放、旋转和水平镜像。角色可以设置层级、角色类型、路线速度、路线显示、循环和碰撞方式。水流可以设置图层、流向、流速和碰撞。

## 默认资源与自定义资源

默认资源有背景图、树木、角色和房屋四类。背景图分类提供带缩略图预览的“村庄背景”和“村庄学校背景”两张独立场景；点击预览图后会提示“当前场景已有背景图，是否替换？”。点击树木或房屋后，再到画布点击即可放置；点击默认角色会直接在场景中创建角色。

自定义资源页按当前分类上传 PNG、JPEG 或 WebP。上传图会转换成 PNG 并保存到 `user://director_desk/assets/`，以后可从自定义资源页再次使用。自定义背景可替换当前背景；其他自定义图片按静态 bottom-center 锚点元素放置。自定义人物序列帧和普通元素通用路线属于后续版本，目前自定义角色图片先作为静态元素。

## 章节与场景

底部 Project 左侧是章节树，右侧是当前章节的场景卡片。先选择章节，再点击“新建场景”，新场景会建立在该章节下。场景卡片可以打开、重命名、删除和上下排序；章节的重命名、删除和排序继续通过章节操作完成。删除章节会连同章内场景一并删除，且至少保留一个章节。

场景背景支持村庄预设、空白画布和上传图片。上传图最长边会缩到 2048 px；布局坐标采用 UV，所以更换背景尺寸后元素、区域、水域和路线仍按比例定位。当前只播放当前场景，不跨章节连播。

## 水流、底图裁片和角色路线

工具条“矩形水域”拖出可缩放矩形；“套索水域”逐点勾画多边形水流，双击、点回起点或按 Enter 闭合。完成后工具保持激活，方便连续创建；按 Esc 返回移动。水面使用沿局部流向连续移动的细流线、高光波纹和轻微折射表现真实流动，原有柔和漂移仅作为很淡的水面薄雾保留。每块水域可独立设置图层、流向、流速和碰撞，水域可以共边但不能面积重叠。

流向：选中水域后，在右侧点“画流向线”，沿水流方向在水域内逐点点击，或按住鼠标拖出曲线；双击、Enter 或松开拖动即完成一条，工具保持激活可继续画下一条，Backspace 删除末点，Esc 取消当前线 / 退出。可以画多条线：水流离哪条线越近就越跟随它，处在两条线中间时按两条线方向的合力流动，适合弯曲河道或汇流。选中水域时画布会显示流向线和小箭头预览合成后的方向；右侧可对每条线“反向”或“删除”。没有画流向线时，整块水域按画布上的方向箭头流动，拖动箭头端点即可改方向。

“底图裁片”从背景逐点圈出区域，它不创建水域。该区域会作为独立元素出现在 Hierarchy，并可设置显示层级。选择背景时也能看到背景下已有多少块裁片。

选择角色后点击工具条“路线”或 Inspector 的“编辑路线”，在画布点击添加路线点。只有当前角色路线显示并接受编辑；每个角色有独立速度、路线显隐、循环和碰撞方式。播放时所有有有效路线的角色同时行动。

## 工具状态

- 移动：按 `V` 切换；点住对象上的任意位置拖动时保留抓取偏移，不会跳到鼠标中心。方向键微调 1 px，`Shift+方向键` 微调 10 px。
- 缩放：按 `Ctrl/Cmd+T` 或点击工具；先选中普通图片元素，再拖动四角控制点等比缩放，也可用 Inspector 滑杆精确调整。
- 旋转：先选中普通图片元素，再拖动选框外圈；按住 Shift 以 15° 吸附，也可在 Inspector 输入角度。旋转值随场景保存。
- 镜像：选中普通元素后水平镜像并保存。
- 路线：当前完整支持角色；树木、房屋和自定义静态图片的通用路线后续开放。

中键平移和滚轮缩放是独立的画布浏览操作：中键可以在框选、套索、路线或元素变换过程中临时按住拖动画面，松开后原操作继续；不会切回移动工具或清空已经画出的点。滚轮以鼠标所在位置为缩放中心。

## 环境、昼夜与下雨

选择 Hierarchy 的“环境与下雨”，可设置早晨、中午、傍晚、夜晚四种画面色调。“夜晚环境亮度”默认 0.35，调到 0 时没有任何基础环境光、画面全黑，调到 1 时等于旧版默认夜晚亮度。月光是独立的持续冷蓝光源：即使环境亮度为 0，提高月光强度也能重新看见带明显冷色的场景。闪电则是更接近白色的瞬时冷光，同样能在全黑环境中短暂照亮场景。

先启用下雨，分别设置 0–1 的“雨水强度”和“雨水密度”，再点“圈选（有水花）”或“圈选（无水花）”，沿屋顶、树冠或地面逐点框定，双击、点回起点或按 Enter 闭合。强度控制雨滴速度、粗细以及水花大小，密度独立控制雨滴和落点数量。框线本身不是碰撞边界；系统会在每个周期于区域内部重新随机落点，并为每个落点生成一滴从屏幕顶部落下的对应雨滴，不再额外叠加没有落点的前景雨线。上方落点的行程较短，下方落点的行程较长；雨滴到达落点后终止，每滴雨的水花尺寸与该雨滴自身大小一致。关闭水花时仍按相同方式落下并终止，只隐藏飞溅。每块区域会出现在 Hierarchy 中；选中后可随时切换水花、启用状态和显示层级，也可拖动多边形顶点修正范围。

“下雨时启用打闪”会产生冷色的随机双段闪光，并短暂显示闪电分叉；可以分别调整闪光强度和出现频率。风可以独立开启并设置八个方向、0–1 风力与独立风速：雨滴倾角会随风力从 0° 连续增加，水平或斜向风达到最大风力时倾角为 60°，并朝风向偏转；向上或向下的风保持雨滴垂直，只改变下落速度。风速滑块使用 1×–20× 的指数档位，最低档就是旧版最高速度，因此低档仍容易微调，高档可快速变化。每轮风丝都会重新随机位置、轮廓和是否出现，由平滑前端沿风向逐步延伸，旧尾迹缓慢消失，已出现部分只做轻微摆动，少量风丝末端会形成短小卷尾。

环境和天气都是纯视觉效果，不修改角色、水流或碰撞。

修改 Inspector 参数只局部刷新画面：当前相机位置、缩放倍率、角色当前位置以及正在进行的套索/框选状态都会保留。

## 播放、保存与快捷键

顶栏“播放/停止”控制当前场景。播放时编辑锁定；暂停、停止和回到开头继续沿用现有播放语义。修改后 300 ms 自动保存，顶栏显示保存状态；每个场景保留 `.bak`。旧 `scene_layout.json` 会一次性迁移，旧水面 mask 保留为只读显示。

| 按键 | 作用 |
| --- | --- |
| Space | 播放 / 暂停当前场景 |
| Esc | 取消框选/套索/路线编辑，或停止播放 |
| Enter | 闭合水域、底图区域或降雨区域套索 |
| Backspace | 删除当前角色路线末点 |
| Ctrl/Cmd+S | 立即保存 |
| Ctrl/Cmd+Z | 撤销 |
| Ctrl/Cmd+Shift+Z、Ctrl+Y | 重做 |
| V | 移动工具 |
| Ctrl/Cmd+T | 缩放工具 |
| 方向键、Shift+方向键 | 所选图片元素微调 1 px / 10 px |
| Shift | 移动时临时吸附 8 px 网格；旋转时吸附 15° |
| 鼠标滚轮、+、- | 缩放画布；滚轮以鼠标位置为中心 |
| 鼠标右键/中键拖动 | 平移画布；中键不打断当前操作 |
| F1 | 打开中文帮助 |
| F3 | 显示碰撞调试 |

文本框或文件对话框打开时，全局快捷键不会触发。P0 优先桌面浏览器鼠标键盘；窄屏可用抽屉访问两侧面板，但不承诺手机精细编辑。
