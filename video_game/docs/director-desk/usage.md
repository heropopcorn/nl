# 导演台用法（P0）

运行时编排短镜头：多场景、矩形水域、一名角色的折线路线、下雨预览。不是 RPG，也不是完整关卡编辑器。

打开 `video_game/project.godot`，按 **F5**。桌面与 Web 是同一套中文 HUD。数据只写 **`user://director_desk/`**（浏览器里通常是 IndexedDB）。**不会**覆盖 `art/approved/`，也不写 `codex/asset-gen/`。本机保存，不是云同步。

## 界面

- **顶栏**：导演台、场景名、保存状态（保存中… / 已保存 / 保存失败）、撤销 / 重做、帮助。
- **左栏**：场景列表、搜索、新建。卡片菜单可重命名、删除（删除要二次确认）。
- **画布**：背景、水域框、角色与路线。右键/中键拖移镜头，滚轮缩放。
- **右栏**：场景（更换背景、道具/碰撞开关）/ 水域 / 角色 / 天气。
- **底栏**：选择、框选水域、编辑路线；回到开头、播放 / 暂停、停止、循环预览。

窗口窄于 900 px 时，左右栏变成互斥抽屉（顶栏「场景」「属性」）。

## 新建场景

名称 1–40 个字符。背景三选一：

| 来源 | 效果 |
| --- | --- |
| 村庄预设 | 批准地皮 `chatgpt-terrain-ground-approved.png`，默认显示切片道具 |
| 空白画布 | 1152×864 中性底 |
| 上传背景 | PNG / JPEG / WebP，最长边缩到 2048，最大 12 MiB |

首次启动若没有导演台数据，会自动建「示例村庄」。若仍存在旧版 `user://scene_layout.json`，会一次性迁成「从旧版导入」（旧文件保留）。旧水面 mask 只读，请用矩形重新框选。

## 水域

「框选水域」后在画布拖矩形；若松开时太小，可继续拖动或在对角再点一次结束。每块可设八向流向、流速、碰撞。相邻可共边，**面积重叠会标红**，此时不能保存、不能播放。碰撞总开关在「场景」页，与每块「启用碰撞」同时生效。

## 角色

P0 每场 1 人，可选 **农夫** 或 **蓝衣农夫**（占位图）。编辑路线：左键加点，拖点调整，Backspace 删末点。少于 2 个路线点可以保存，但不能播放。默认忽略碰撞，方便穿水面预览。

## 天气与预览

天气页：启用 + 下雨强度（纯画面，不改速度/碰撞）。底栏播放从出生点沿路线走；暂停不跳变；停止回到出生点。预览时不能改水域或路线。WASD 会取消预览并走位，**不会改已存路线**。

## 快捷键

| 键 | 作用 |
| --- | --- |
| Space | 播放 / 暂停 |
| Esc | 取消框选 / 结束路线编辑 / 停止预览 |
| Ctrl/Cmd+S | 立即保存 |
| Ctrl/Cmd+Z | 撤销（约 50 步） |
| Ctrl/Cmd+Shift+Z 或 Ctrl+Y | 重做 |
| F1 | 帮助 |
| F3 | 碰撞调试 |

文本框或文件对话框打开时，全局快捷键不会触发。修改后 300 ms 自动保存。

旧画刷编辑器说明仍见 [`../custom-editor-mvp.md`](../custom-editor-mvp.md)，P0 导演台已取代它作为默认 UI。
