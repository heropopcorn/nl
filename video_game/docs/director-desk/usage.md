# 导演台 V2 使用说明

导演台用于在 Godot 运行时搭建并预览短镜头。打开 `video_game/project.godot` 后按 **F5**；桌面和 Web 使用同一套全中文界面。数据保存在 `user://director_desk/`，浏览器中对应本站 IndexedDB，不是云存档。

## 编辑模式与播放模式

顶栏始终显示当前状态：绿色「编辑模式」可摆场景，橙色「播放模式」会锁住编辑。点击顶栏按钮或底栏播放控制切换。

- 编辑模式：选择对象、拖动元素、圈底图区域、画水域、编辑角色路线。
- 播放模式：当前场景里的所有启用角色同时按各自路线和速度行走；可暂停、继续、停止或回到开头。
- 本版明确播放**当前场景**，不会自动跨场景或跨章节连播。

Space 播放/暂停，Esc 取消当前圈选或停止播放，Ctrl/Cmd+S 立即保存，Ctrl/Cmd+Z 撤销。

## 章节与场景

左栏按「章节 → 场景」展示：

1. 点击「新建章节」，输入 1–40 字名称。
2. 点章节标题选中章节，再点「新建场景」；新场景会建立在当前章节下。
3. 章节的「章节操作」可上移、下移、重命名或删除。
4. 场景的「…」菜单可上移、下移、重命名或删除。

删除场景或章节都会弹出确认。删除章节会连同章内场景一并删除；至少保留一个章节。旧版没有章节的索引会自动迁入「第一章」。

场景背景支持村庄预设、空白画布和上传图片。上传图最长边会缩到 2048 px；布局坐标采用 UV，所以更换背景尺寸后元素、区域、水域和路线仍按比例定位。

## 元素与显示层级

右栏属性区下方有可收起的「素材抽屉」，按「房屋 / 树木 / 道具」分类显示独立素材。展开抽屉后，把素材卡片直接拖到画布上的目标位置即可创建元素；也可以单击卡片，再到画布点一下完成放置。按 Esc 可取消等待放置。

抽屉不会替代「场景 / 水域 / 角色 / 天气」属性页，不需要素材时可收起，为属性编辑留出更多空间。元素节点的原点是图片底部中央，作为脚底锚点；放置后可以继续在画布拖动调整。

- 每个元素有整数「显示层级」，范围 -100～100；数值越高越靠前。
- 角色和底图区域也使用同一套整数层级。
- 不同层先比较层级；同层交给 Godot 的 Y 排序，脚底越靠下越靠前。
- 元素可调缩放，并可删除。

内置村庄道具仍可整体显隐；新添加的元素是独立可编辑实例。

## 底图区域圈层

点击「套索圈选底图层」或底栏「圈底图层」，在画布逐点勾画。双击、点回起点或按 Enter 闭合。创建后点紫色轮廓选中，在右栏设置整数层级。

实现规则：区域会把背景图对应像素裁成一块独立 `Polygon2D` 并放到指定层级。它适合制作矮墙、平台边缘等遮挡；区域本身不增加碰撞。多个区域允许相交，较高层级优先；同层按节点 Y 排序，因此建议有明确遮挡意图时使用不同层级。

## 流水与水域

水面使用多层定向流纹、细流线和波光，不再只是半透明雾层。每块水域有独立方向、流速和碰撞。

有两种建法：

- 「矩形框选」：拖出矩形；选中后拖四角精确调整大小，拖内部移动，拖方向圆点改变流向。
- 「套索 / 多边形」：逐点勾画弯曲水域，双击、回点或 Enter 闭合；选中后可逐个拖白色控制点，也可拖内部整体移动。

水域可以共边，但不能有面积重叠。重叠会标红并阻止保存和播放。右栏可选八向流向、连续流速和单区碰撞；「场景」页另有碰撞总开关。

## 多角色与路线

右栏「角色」页可添加多名角色。角色会列在页首，也可以直接点画布上的角色选择。

- 只有当前点选角色的路线会显示和接受编辑，避免多条路线混在一起。
- 点击「编辑路线」后，在画布左键加点；拖动出生点或路线点调整，Backspace 删除末点。
- 每条路线可单独显示/隐藏，并设置 20～600 px/s 的速度、循环和碰撞方式。
- 每个角色也有整数显示层级；同层按脚底 Y 排序。
- 播放当前场景时，各角色从各自出生点同时出发，各走各的路线；暂停和停止会统一作用于全体。

没有有效路线的角色会留在出生点，不阻止其他角色播放。至少一名角色需要有出生点之外的目标点。

## 保存、兼容与快捷键

修改后 300 ms 自动保存，顶栏显示「保存中 / 已保存 / 保存失败」。每个场景保存一份 `.bak`；当前文件损坏时会尝试恢复。旧 `scene_layout.json` 会一次性迁移，旧水面 mask 保留为只读显示。

| 按键 | 作用 |
| --- | --- |
| Space | 播放 / 暂停当前场景 |
| Esc | 取消框选/套索/路线编辑，或停止播放 |
| Enter | 闭合水域或底图区域套索 |
| Backspace | 删除当前角色路线末点 |
| Ctrl/Cmd+S | 立即保存 |
| Ctrl/Cmd+Z | 撤销 |
| Ctrl/Cmd+Shift+Z、Ctrl+Y | 重做 |
| Shift | 拖动时临时吸附 8 px 网格 |
| 鼠标滚轮、+、- | 缩放 |
| 鼠标右键/中键拖动 | 平移画布 |
| F1 | 打开中文帮助 |
| F3 | 显示碰撞调试 |

文本框或文件对话框打开时，全局快捷键不会触发。窗口窄于 900 px 时，左右栏变成顶栏可切换的抽屉。
